# m11s Helm Charts

Helm charts for m11s platform services, published on [ArtifactHub](https://artifacthub.io).

## Usage

```bash
helm repo add m11s https://m11s-io.github.io/charts
helm repo update
```

## Charts

| Chart | Description |
|-------|-------------|
| [fider](./charts/fider) | Self-hosted user feedback platform |

## Publishing

Charts are maintained in the private monorepo and published here via CI.
